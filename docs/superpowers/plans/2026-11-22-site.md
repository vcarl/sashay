# @vcarl/sashay site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `apps/site`: a custom landing page whose hero and demos run the real `@vcarl/sashay`, plus ten short Starlight docs pages re-themed to match the approved mock.

**Architecture:** Astro + Starlight. The landing page is a custom Astro page (not a Starlight page) built from the mock's markup and CSS. One token file (`src/styles/tokens.css`) feeds both the landing CSS and the Starlight override, so they cannot drift. Every runnable example is a module `src/examples/<name>.ts` exporting `mount(el: HTMLElement): () => void`; a `Demo.astro` component shows that file's source (`?raw`) next to a frame running it, so the code shown is the code run.

**Tech Stack:** Astro, `@astrojs/starlight`, `@astrojs/react` (React docs page only), Fontsource (variable), `@vcarl/sashay` via `workspace:*`, Playwright + `@axe-core/playwright` + `lighthouse` (verification only).

**Spec:** `docs/design/site-direction.md`, `docs/design/landing-mock.html` (+ `landing-desktop.png`, `landing-mobile.png`), `docs/api.md`, `AGENTS.md`. Scaffold and root scripts: Task 1 of `docs/superpowers/plans/2026-11-22-library.md`.

## Global Constraints

- Branch `build/1.0`. Other agents commit concurrently: **append-only commits; no rebase, reset, or amend.** Stage only files you created or edited; never `-A`/`-u`/directory adds. Never push, add remotes, deploy, tag, or touch versions. No deploy step or workflow.
- `apps/site` is `"private": true`, `"version": "0.0.0"`, depends on `"@vcarl/sashay": "workspace:*"`. Vanilla API from `docs/api.md` for the landing page and docs; React only on the React page.
- Root script `site:build` (exact name). Existing root scripts (`typecheck`, `lint`, `test`, `test:browser`, `bench`, `build`, `size`) must keep passing; Biome ignores `apps/site/dist` and `.astro`.
- `base` = `process.env.SITE_BASE ?? "/"`, set in `astro.config.mjs`. Every internal link and asset uses `import.meta.env.BASE_URL`; no hard-coded `/` paths.
- Palette, type, layout and copy exactly as `site-direction.md`: paper `#F6EEDC`, ink `#1B1A17`, mute `#5B574D`, cobalt `#1F3FCB`, tomato `#E4472C`, butter `#FFC846`, mint `#7FD1B4`. Never paper text on tomato. Fraunces (display, opsz 144, wt 500; "sashay" italic WONK 1 SOFT 100), Instrument Sans (body 17px/1.5), JetBrains Mono (code). Headings are sentences with full stops. No exclamation marks, no emoji, no gradients.
- Motion: 240ms `cubic-bezier(.2,.8,.2,1)`; `prefers-reduced-motion: reduce` sets duration 0; no autoplay or scroll animation.
- Fonts self-hosted through `@fontsource-variable/*` imports only. No requests to Google Fonts or any CDN at runtime.
- No default Starlight look: no stock Starlight accent, no Starlight hero, no emoji bullets.
- Docs pages short (about one screen of prose), each with one runnable `Demo`, except the API reference (the tables from `docs/api.md`, no demo).
- Minimal code: no CMS, no i18n, no search customisation, no analytics, no component beyond those named here.

## Review Focus

1. **JS disabled or demo failing to mount:** hero panes still render as readable stacked content (the markup is complete HTML; sashay only enhances). Pinned in Task 5.
2. **`SITE_BASE=/sashay/` build:** every link, font, script and CSS URL resolves under the base. Pinned in Task 1 and Task 8.
3. **Mobile at 390px:** compact mode engages (frame under 40rem), no horizontal page scroll, tab strip reachable by keyboard. Pinned in Task 5 and Task 8.
4. **Reduced motion and keyboard:** edges focus with a butter ring, arrows move snaps with no drag required; reduced motion zeroes durations. Pinned in Task 5.
5. **Stale `?layout=` in the URL** (garbled or from another demo): hero falls back to the default, never throws. Pinned in Task 5.
