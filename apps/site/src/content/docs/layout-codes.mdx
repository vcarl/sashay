`onChange` hands you a code: one hex digit per visible divider, plus the spine offset and the drawer bits. It fires on release, click, keypress or a pane-list change, never during a drag. Pass a saved code back as `layout`; invalid input falls back to `defaultLayout`.

`sash.layout` reads the current code at any time. `setLayout(code)` applies a code without firing `onChange`; `fit(fractions)` sorts and clamps the fractions, moves to the nearest snaps and fires it.

The code stores geometry only. Which panes exist is app state, such as the route, so store it separately.
