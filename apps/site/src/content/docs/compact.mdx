---
title: Compact mode.
description: What happens on a phone.
---

Below `compactBelow` (a `Length`, `"40rem"` by default) a frame switches to compact mode. The edges become a tab strip, and drawers open as overlay sheets, one at a time. The frame gets `data-compact`, so your CSS can follow.

The width is the frame's, not the window's, so a narrow sidebar frame goes compact on a wide screen too.

{/* demo */}

```ts
createSashay(frame, {
  panes,
  compactBelow: "36rem",
});
```

```css
[data-compact] .toolbar {
  flex-direction: column;
}
```
