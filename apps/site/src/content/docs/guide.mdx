This page builds one small React app: a chart of houseplants with three panes, Chart, Nearby and Plant. Each section adds one feature, shows the lines that changed, and runs the app as it stands. The full source is on the [Demos](../demos/) page.

## Install

sashay is one ESM package. You use it through React components; underneath is a core with no runtime dependencies, which you can also [use without React](#without-react).

```sh
pnpm add @vcarl/sashay react react-dom
```

React is a peer dependency and needs version 19 or later. Import the components and the stylesheet once. The styles live in `@layer sashay`, so your own CSS wins without a fight.

```tsx
import { Pane, Sashay } from "@vcarl/sashay/react";
import "@vcarl/sashay/style.css";
```

## Your first frame

A frame is a `<Sashay>` with a height. Put one `<Pane>` inside it per pane, in order. sashay creates the edges, grips and close buttons itself.

Each pane says how it opens. `focus` is the fraction of the frame a pane opens to; `title` labels its edge, its compact tab and its close button. `defaultLayout` places the dividers: `[1, 1]` pushes both to the right edge, so only Chart is open.

Your app opens panes with `reveal(id)` and closes them with `close(id)`, on the handle that `ref` gives you. Click a plant and Nearby slides in, listing the plants closest to it. Click the plant again in the list and its card opens in the third pane, at equal thirds because Plant sets `opensTo`. The leaf × closes the rightmost open pane; closing Nearby calls its `onClose`, which clears the pick.

## Keep a point in view

A pane that another pane slides over isn't squished. It keeps its `focus` width and the next pane covers part of it. Give the pane `keepInView` and sashay slides its content left, as little as it can, so that point stays inside the slice that's still showing. Pass `null` to let go.

`keepInView` is a `Length` measured from the pane's left edge: a number is pixels, and `"40%"` is 40% of the pane's width. The chart here is a fixed 720 pixels wide, so the app passes the picked plant's x in pixels. The chart's `focus` of 3/4 keeps it drawn at least that wide while it's covered.

This frame opens squeezed, with the Lemon tree picked far over on the right. Drag Nearby's edge back and forth, or pick other plants in the list, and the dot stays in view. A covered pane is inert, so while the chart is squeezed you pick from the list.

## Layout in the URL

`onLayoutChange` hands you a code: one hex digit per visible divider, plus the spine offset and the drawer bits. It fires on release, click, keypress or a pane-list change, never during a drag. Pass a saved code back as `layout`; invalid input falls back to `defaultLayout`.

In your app, `onUrl` would be `history.replaceState`, as below; this little browser keeps its own address bar instead, so the frames on this page leave yours alone. Drag an edge and watch `?layout=` change. Pass the saved code back as `layout` and the panes come back where you left them.

<DemoApp name="plants" region="url" options={{ drawer: false, initial: { layout: "69", plant: "pothos", card: true } }} />

`ref.current.layout` reads the current code at any time. `setLayout(code)` applies a code without firing `onLayoutChange`; `fit(fractions)` sorts and clamps the fractions, moves to the nearest snaps and fires it. The code stores geometry only. Which panes exist is app state, such as the route, so store it separately.

## Drawers

Give a pane's edge a `drawer` and that edge opens a panel `width` wide. `width` is a `Length`: a CSS length string or a number of pixels. The drawer's `content` is any React node. sashay adds a toggle beside the edge, with `aria-expanded`; `toggleDrawer(id)` opens it from code.

Here the Chart edge holds a **Window** drawer. Pick the way your window faces, and the plants it can't give enough sun turn hollow.

## Compact mode

Below `compactBelow` (a `Length`, `"40rem"` by default) a frame switches to compact mode. The first edge becomes a tab strip, every other edge a 12px grip whatever its `width`, and drawers open as overlay sheets, one at a time. The tab strip lists up to six panes; past six, the oldest fold into the spine, so every pane stays a tap away. The frame gets `data-compact`, so your CSS can follow.

The width is the frame's, not the window's, so a narrow sidebar frame goes compact on a wide screen too. This frame passes `compactBelow="100vw"`, so it is always compact.

<DemoApp name="plants" region="compact" options={{ compactBelow: "100vw", initial: { plant: "monstera" } }} />

## Styling

The stylesheet sits in `@layer sashay`, so any unlayered rule of yours beats it. Theme the frame with `--sashay-*` custom properties for colour, radius, font size and shadow; every one has a fallback. `<Sashay>` passes `className` and other `div` props to the frame, and each `<Pane>` renders a `[data-sashay-pane]` element, so style them however you like.

State shows up as attributes: `data-covered`, `data-closed` and `data-offscreen` on panes, `data-dragging` and `data-compact` on the frame. The [styling hooks](../reference/#styling-hooks) table lists them all.

This one opens at equal thirds. The chart is covered, so it holds the picked plant in view too.

## Navigation stacks

A stack is just an array in state. Picking an item adds a pane on the right; going back removes it. There are no push or pop helpers: render a `<Pane>` per entry and sashay diffs them by `id`. A new pane slides in and opens to its `focus`; a removed pane closes, gives its width to its neighbour, then leaves.

When the open panes no longer fit, the oldest fold into one spine at the left with a count. Clicking it, or pressing ← on it, reveals the newest hidden pane. Closed panes never fold, so a fixed workspace that fits never shows a spine.

This house opens room by room, down to the contents of a drawer.

## Without React

The components are a thin wrapper over `createSashay`, a vanilla DOM controller with no dependencies. Use it directly from another framework or library, or to build your own wrapper. Put one `[data-sashay-pane]` element per pane in the frame, describe the panes, and call the handle's methods; when the list of panes changes, call `update({ panes })`.
