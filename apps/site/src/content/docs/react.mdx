`<Sashay>` takes `layout`, `defaultLayout` and `compactBelow` as the options do, and `onLayoutChange` in place of `onChange`. Its `ref` gives you the handle methods. Each `<Pane>` takes every `PaneOptions` field, plus `keepInView` (a `Length` or `null`) and `onClose`, which fires when the user closes this pane. `edge.drawer` also takes `content`.

`<Pane>` renders its own element and registers with the nearest `<Sashay>`, so wrap it or render it conditionally: that is how a stack grows. `children` can be a function of `{ offscreen }`, to unmount heavy content in very deep stacks. Server rendering produces percentage widths from `layout`, so the first paint matches the hydrated layout on frames wide enough for its grid. Narrower frames (compact mode, or a coarser snap grid) re-snap on hydration.
